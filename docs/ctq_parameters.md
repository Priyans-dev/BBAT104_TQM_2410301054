# Critical to Quality (CTQ) Parameters

**Project:** Restaurant Billing System
**Quality Goal:** Q06 - Reduce Duplicate Entries

| CTQ ID | Customer Need | CTQ Parameter | Measurable Target |
|---|---|---|---|
| CTQ-01 | No duplicate menu items | Duplicate menu items stored in database | 0 duplicates |
| CTQ-02 | Every bill is unique | Duplicate bill IDs generated | 0 duplicate bill IDs |
| CTQ-03 | Accurate bills | Billing calculation errors | 0 errors in total, tax and discount |
| CTQ-04 | Fast order processing | Time to generate one bill | Less than 3 seconds |
| CTQ-05 | Clean and valid data | Invalid entries accepted by the system | 0 invalid entries |
| CTQ-06 | Safe against mistakes | Accidental add, update or delete actions | Confirmation required for every change |
| CTQ-07 | Easy to use | Time for a new user to create a bill | Less than 2 minutes |
